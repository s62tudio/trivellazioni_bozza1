# Trivellazioni Italia Srl — nuovo sito web (bozza 1)

Sito aziendale realizzato con Next.js 16, React 19, Tailwind CSS 4 e Motion.
Direzione grafica "Carotaggio": scorrendo si scende negli strati del terreno.

## Struttura

- `site/` — il sito (codice, contenuti, immagini, documenti). Istruzioni dettagliate in [`site/README.md`](site/README.md).
- `Trivellazioni-Italia-nuovo-sito-scelte-progettuali.pdf` — scheda di una pagina per il cliente.

## Avvio in locale

```bash
npm --prefix site install
npm run dev
```

Poi apri http://localhost:3000.
